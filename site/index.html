Configuração MT5

Use login, senha e servidor dentro do MetaTrader 5. O painel conversa com o EA Bridge via Supabase/Netlify.

Dados da conta

A senha não é salva no painel. Faça login diretamente no MetaTrader 5: Arquivo > Abrir Conta / Login na conta de negociação.

Como conectar

  1. Abra o MetaTrader 5 da Deriv.
  2. Faça login com Login ID, senha e servidor.
  3. Copie mt5/DF_Forex_Pro_Bridge.mq5 para MQL5/Experts.
  4. Adicione a URL do Netlify em Tools > Options > Expert Advisors > WebRequest.
  5. Arraste o EA para um gráfico e configure Bridge ID/Secret.
  6. Volte ao painel e clique em Iniciar operações.
