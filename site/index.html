1. CONEXÃO

Conectar Deriv

Use a conexão por token para operar imediatamente. O OAuth continua disponível, mas depende do App ID correto no painel da Deriv.

Criar token na Deriv

Para operar, o token precisa ter escopos Read e Trade. Para apenas testar conexão, use somente Read.

O login oficial exige um App ID real criado no Deriv Application Manager. Configure o Website/OAuth Redirect URL como https://df-forex.netlify.app/deriv-callback.html.

Conta Deriv MT5 detectada Use este modo para Forex/CFD com MetaTrader 5, lote, stop loss e take profit.

O Web Terminal da Deriv mostra o login, mas não roda Expert Advisor. Para operar automaticamente em MT5, instale o MT5 desktop/VPS e o arquivo mt5/DF_Forex_Pro_Bridge.mq5.
